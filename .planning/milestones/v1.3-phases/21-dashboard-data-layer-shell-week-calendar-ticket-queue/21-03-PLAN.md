## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser (WeekCalendar.svelte) -> derive.ts (pure) | No trust boundary — `WeekCalendar` receives already-derived, already-scoped data as props; it performs no data fetch and no further filtering of its own. |
| Browser (Dashboard.svelte's week-nav) -> local `$state` only | `semanaBase` is a local, non-persisted `$state` (spec-ui.md §0.9: no store, no cache) — it never reaches the network or `localStorage`, closing off any concern about a navigable date leaking or persisting across sessions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-06 | Tampering | `agenda`'s `vencido`/today-highlight math vs. week navigation | medium | mitigate | `hojeIso` (the real current date) and `semanaBase` (the navigable displayed week) are two separate `$state`/`const` values in `Dashboard.svelte`; `agendaPorDia` always receives `hojeIso` for its `hoje` parameter regardless of which week `semanaBase` currently points to, so paging through weeks can never make a genuinely-overdue item stop being flagged as overdue, or vice versa. |
| T-21-07 | Information Disclosure | Weekend `Popover` content | low | accept | Lists only items already present in the same single, `donoId`-scoped `dashboardQuery.ts` result already rendered elsewhere on the page — no new data is fetched to populate it. |

</threat_model>
