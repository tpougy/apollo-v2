<objective>
Close the three silent-failure/misleading-documentation gaps VAL-01/VAL-02/VAL-03 identified in the RBR
onboarding: `apollo rotina template criar`/`editar --regra-competencia` currently accepts ANY string and
only rejects an unsupported value much later, silently, inside `gerar-instancias` (`skipped:
regra_competencia_nao_suportada`) — this plan makes the CLI itself reject it at write time by binding
`type=click.Choice(REGRAS_COMPETENCIA_SUPORTADAS)` (imported from `apollo_cli.routine_job`, the module's
own single source of truth) on both commands, mirroring the exact pattern the same functions already use
for `--tipo-geracao`. `--propagar-atraso-soft`'s help text is rewritten so it no longer implies the flag
does anything at generation time (it is stored but never read by `gerar-instancias`, C-09, explicitly out
of scope for this milestone — no behavior changes here, only truthful documentation). `instancia status`'s
docstring is corrected to stop calling `dedupeKey` a hash, matching `routine_job.py`'s own canonical
wording (plain `templateId:competencia:dataPrevista` concatenation).

Because `--regra-competencia` has been free-form since Phase 5, several pre-existing CLI tests and web e2e
specs pass placeholder values (`mes_corrente`, `mes-corrente`, `mes_seguinte`, `encadeada`, `R`) that are
NOT in the new enum, purely as unrelated seed data for Dashboard/FocusDialog UI checks. Tightening the
validation would silently break all of them on the very next run — this plan's second task repairs every
one of those fixtures before it can happen.

Purpose: a template with an invalid `regraCompetencia` is refused immediately, with the accepted values
named in the error itself — never silently accepted and only revealed deep inside `gerar-instancias`.
`propagarAtrasoSoft`'s `--help` stops implying it is an active feature. `dedupeKey`'s docstring stops
contradicting `routine_job.py`'s own canonical description.
Output: `cli/apollo_cli/entities/rotina.py` with `click.Choice`-enforced `--regra-competencia` on both
`criar`/`editar`, corrected `--propagar-atraso-soft` help text, a corrected `instancia.status` docstring;
`docs/ai-usage/CLAUDE.md`'s corrected cheatsheet line; two new permanent live regression tests; and every
pre-existing CLI/e2e fixture that would otherwise break, repaired.
</objective>
