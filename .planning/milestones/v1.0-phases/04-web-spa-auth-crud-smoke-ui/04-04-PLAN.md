| Browser -> InstantDB | `donoId` rules enforced server-side; link writes are NOT validated by InstantDB |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-11 | Tampering | Parent-type switch on edit leaving a stale link | mitigate | Task 1 requires confirming the shipped unlink-on-switch behaviour before writing the definition; Task 2 Test 4(c) asserts the old link is actually gone in the server's readback |
