<environment_facts>
- `cli/pyproject.toml` has `[tool.ruff] src = ["."]`. When ruff is invoked with a path outside `cli/` (e.g. `../shared/scripts`), it discovers configuration by walking up from *that file*, reaching `shared/` then the repo root — neither of which has a `[tool.ruff]` section. The file would therefore be linted with ruff's defaults, silently missing `extend-select = ["I", "ANN"]`. Passing `--config pyproject.toml` explicitly (from `cli/`) forces one config for all supplied paths and is the fix used throughout Phase 2.
- `ty`'s CLI flag surface is pre-1.0 (`ty 0.0.69`). Whether it accepts a config/project flag must be checked with `uv run ty check --help` at execution time rather than assumed.
- Phase 1's `verify-phase-01.sh` is the established shape to mirror: a `set -euo pipefail` bash script with one clearly labeled section per requirement, `cd`-ing to the repo root first, ending with a single `PHASE 01 VERIFIED` line. Read it before writing the Phase 2 equivalent.
- `biome.json` is intentionally NOT extended to cover `shared/*.json` — both new JSON files are data (one generated, one a fixture), and their formatting is owned by their producers. Do not change `biome.json` in this plan; document the rationale instead.
</environment_facts>
