<objective>
Restructure `web/src/lib/Shell.svelte` in place so it presents one coherent header/toolbar row
(app identity + user/logout action, per SHELL-01), one consistent nav active-state and single
flat-wrapping-row overflow strategy for all 9 entities (per SHELL-02, per CONTEXT.md's locked
"no Tabs, no scroll container" decision), and exactly one outer content-frame wrapper (max-width +
horizontal padding + vertical rhythm) around the nav and the active `EntityScreen` mount point,
inherited identically by all 9 entities (per SHELL-03). This is the architectural fulcrum of v1.2
(ARCHITECTURE.md): because `EntityScreen` remounts fresh on every nav click via `{#key ativo}` but
`Shell` mounts once per session, the outer frame belongs here — applied exactly once — so no
future entity screen ever needs to declare its own page-level width/padding.

`web/src/App.svelte` is out of this phase's touch-set (per 13-PATTERNS.md's file classification):
its root `<h1>Apollo v2</h1>` stays byte-identical, since `design-system.spec.ts` asserts computed
`font-size`/`font-weight` on it. ROADMAP's "replacing the stray root `<h1>` and floating logout
button" success criterion is satisfied functionally — `Shell`'s own toolbar now owns app-identity +
logout chrome that previously had no proper home — not by deleting or restyling that DOM node.

Purpose: This phase must land before `EntityScreen.svelte`'s own polish (Phase 14+) so inner
screen-specific spacing decisions are tuned against an already-final outer frame, not a moving
target. Doing this first also re-proves the full nav-through-all-9-entities Playwright suite
before any entity-internal markup changes begin (ARCHITECTURE.md's Build-Order Implications).

Output: `Shell.svelte` restyled in place with a `shell-header` toolbar, a `Separator`, and a
`shell-content-frame` wrapper; one new Playwright spec (`shell-chrome.spec.ts`) proving the
header/toolbar composition, single content-frame consistency across entities, and the nav overflow
strategy live against the real InstantDB app; the pre-existing `shell-nav.spec.ts` suite and the
full pre-existing Playwright regression stay green.
</objective>
