  <action>
Implement `semanaUtil(hoje: string): { dias: string[]; sabado: string; domingo: string }` using
plain UTC calendar-day arithmetic only — `new Date(`${hoje}T00:00:00.000Z`).getUTCDay()` to get
the weekday index (Sunday=0..Saturday=6), the Monday offset as `(dow + 6) % 7` days back from
`hoje`, then `setUTCDate`/`getUTCDate` stepping forward one calendar day at a time to build
Monday..Sunday. Never call `isBusinessDay`/`addBusinessDays`/`nextBusinessDay` from `bizdays.ts` —
those skip weekends/holidays by design and would shift Friday whenever a holiday falls inside the
target week (21-RESEARCH.md Q2/Pitfall 1). Format every returned date as a plain `YYYY-MM-DD`
string (matching `bizdays.ts`'s own zero-padded ISO string convention) — `dias` holds Monday
through Friday only (5 entries), `sabado`/`domingo` are the same week's weekend dates.

Implement `faixaHeatmap(n: number): 0 | 1 | 2 | 3 | 4` per spec-ui.md §6's fixed cuts: `0` -> `0`,
`1-2` -> `1`, `3-4` -> `2`, `5-7` -> `3`, `8+` -> `4`.

Implement `cargaDoMes(dados: { tarefas: { dataPrevista?: string | null }[]; instanciasRotina: { dataPrevista: string }[]; tickets: { dataPrevista?: string | null }[] }, ano: number, mes: number): Map<string, number>`.

`tipoPrazo` (unlike `agendaPorDia`'s week-band, the heatmap's "afazeres do dia" count per
spec-ui.md §3.4 is unqualified). A `tarefa`/`ticket` with no `dataPrevista` contributes nothing.

  <files>web/src/lib/dashboard/derive.ts, web/src/lib/dashboard/derive.test.ts</files>
  <behavior>
    - A tarefa whose `etapa.projeto.id` matches an entry in `dados.projetos` that has a `fundo`
      produces an Item with `fundoId` equal to that fundo's id; a tarefa with no `etapa`, or whose
      `etapa.projeto` has no matching entry in `dados.projetos`, or whose matching projeto has no
      `fundo`, produces `fundoId: null`.
    - A tarefa's Item `vencido` flag matches `vencido(tarefa.dataPrevista, tarefaConcluida(tarefa), hoje)` exactly.
    - Every `instanciaRotina` whose `dataPrevista` falls within the 7-day window (the 5 `dias` plus
      `sabado`/`domingo`) becomes a `"rotina"` Item regardless of its own `tipoPrazo`; its `fundoId`
      comes directly from `instancia.template.fundo.id` (or `null` when absent); its `vencido` flag
      always uses `concluido = false` (documented decision below).
    - A ticket becomes a `"ticket"` Item only when both `tipoPrazo === "hard"` and `dataPrevista`
      falls within the window; its `fundoId` comes from `ticket.fundo.id` (or `null`); `vencido`
      always uses `concluido = false`. A soft-deadline ticket, or a ticket with no `dataPrevista`,
      never appears in the returned Map (it still appears in the ticket queue — that is a separate,
      unfiltered list built elsewhere).
    - The returned `Map` has exactly 7 keys (the 5 weekday ISO dates plus `sabado`/`domingo`), and
      each day's `Item[]` is sorted: hard-deadline items first (a tarefa or rotina whose own
      `tipoPrazo === "hard"`, or any ticket item, since only hard tickets are ever included), then
      by `tipo` in the fixed order `tarefa`, `rotina`, `ticket`, then by `titulo` ascending —
      deterministic and stable regardless of input order.
    - `rotinasPorFundo` groups a list of instancia-with-template-fundo objects, windowed to the
      same 7 dates as `agendaPorDia`, by `template.fundo.id`; each group's `fundoNome` is
      `template.fundo.nome` (or `null` for the ungrouped bucket); groups are sorted by `fundoNome`
      ascending EXCEPT the `null`-fundo group, which always sorts last regardless of alphabetical
      position; within a group, instancias are sorted by `dataPrevista` ascending, then `id`.
  </behavior>

`id`, `titulo`, `tipoPrazo`, `dataPrevista`, and `fundo: { id: string } | null`; and a
projeto-fundo shape with `id` and `fundo: { id: string } | null`. Export a closed `ItemTipo =
"tarefa" | "rotina" | "ticket"` union and an `Item` interface: `{ tipo: ItemTipo; id: string;
titulo: string; prazo: string; vencido: boolean; fundoId: string | null }`.

Implement `agendaPorDia(dados: { projetos: ProjetoFundoLike[]; tarefas: TarefaAgendaLike[]; instanciasRotina: InstanciaAgendaLike[]; tickets: TicketAgendaLike[] }, semana: { dias: string[]; sabado: string; domingo: string }, hoje: Date): Map<string, Item[]>`.
