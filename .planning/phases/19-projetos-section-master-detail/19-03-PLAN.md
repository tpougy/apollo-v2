<objective>
Complete NEST-03: add the "etapas ▾" list/kanban view toggle over the exact same etapas/tarefas
data Plan 19-02 already fetches and renders as an accordion, and add the "Todas as tarefas" /
"Sem etapa" escape hatch that keeps orphaned tarefas (`tarefas.etapa` is `required: false`)
reachable and editable regardless of which projeto (if any) is selected.

Purpose: this is the second, final requirement of the phase. The kanban toggle proves the same
bespoke query drives two render modes with no duplicate fetch; the "Todas as tarefas" tab is the
literal, spec-mandated escape hatch for the one optional link this milestone's schema has always
had (`tarefas.etapa`) -- without it, an orphaned tarefa becomes permanently unreachable from the
UI the moment `ProjetosSection` replaces the old flat `tarefas` screen access path.
Output: the "etapas ▾" list/kanban toggle, the kanban view itself (fixed-width, non-compressing,
horizontally-scrolling columns), a `Tabs.Root` wrapping the existing detail-column content as its
default tab plus a new "Todas as tarefas" second tab with a "Sem etapa" filter.
</objective>
