<objective>
Plan 17-01 re-confirmed everything Phases 12-16 already built, together, in one pass — but it added
no NEW coverage. This plan adds the coverage the milestone's own success criteria explicitly still
require and that no existing spec provides: a single cross-phase walkthrough that touches Login,

computed pixel values of the spacing scale at each stop (VERIFY-07's "re-checks earlier phases'

the four surfaces that don't have one yet (login, shell/nav, form/dialog, delete confirmation —

(one per capability class) that have never existed in this suite. It closes with the final quality
gates (Biome + svelte-check clean, zero new suppressions) and documents the whole milestone's proof
command in `web/README.md`.

merely because its own screen looks fine in isolation if it visibly breaks the flow established by
an earlier phase" — the only way to make that provable rather than a vibe is a test that actually
walks the flow end-to-end and measures it, which is what this plan builds.
Output: `web/e2e/cross-phase-verification.spec.ts` (8 new live tests), `web/README.md` updated with
the milestone's closing proof paragraph, and a final clean `bun run test:e2e` / `bun run check` /
