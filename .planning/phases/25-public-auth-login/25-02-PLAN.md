    Create `cli/tests/helpers/magic_code.py`, a direct, faithful Python port of
    `web/e2e/helpers/magic-code.ts` (RESEARCH.md's Don't Hand-Roll table — copy the corrected `--grep` phrase
    and sender-check logic verbatim from the TS source; do NOT re-derive it from PROJECT.md C-10's prose,
    which that TS file's own comments document as stale and buggy). Module docstring explains this is a
    line-for-line behavioral port (not a re-implementation from scratch), citing both source files.

    Implement, matching the TS file's structure and constants exactly (same PowerShell command string, same
    6-digit regex, same sender substring, same block-separator regex):
    - A module-level constant for the `orules.ps1 peek` PowerShell command
      (`Set-Location '...'; .\\orules.ps1 peek --folder Inbox --days 1 --grep 'verification code' --body 0
      --max 5"`), copied verbatim from the TS source's `ORULES_COMMAND`.
    - `read_latest_magic_code() -> str | None`: runs
      `subprocess.run(["powershell.exe", "-NoProfile", "-Command", <command>], capture_output=True,
      text=True, check=True)`, splits the captured stdout on the same `\n──\s` block-separator pattern, and
      for the first block (newest-first) whose lowercased text contains `"instantdb.com"`, extracts and
      returns the first `\b(\d{6})\b` match. Returns `None` (not an exception) when no matching block/code
      is found — this Python port intentionally differs from the TS original's `throw` here, since Task 2's
      round-trip test needs a "no code seen yet" baseline read to succeed even when the inbox currently has
      no InstantDB message at all (e.g. the very first run in a fresh environment).
    - `read_magic_code_after(prior_code: str | None, timeout_s: float = 45.0) -> str`: polls
      `read_latest_magic_code()` every 2 seconds until it returns a value different from `prior_code`,
      raising `TimeoutError` with a message naming `prior_code` if `timeout_s` elapses first — mirrors the
      TS `readMagicCodeAfter`'s polling loop and its documented rationale (a stale code from an earlier run
      must never be mistakenly reused; C-10's ~60-90s expiry window means the loop must not itself introduce
      needless delay beyond the 2s poll interval).
    - Never print, log, or persist the extracted code anywhere except returning it to the caller (RESEARCH.md
      Security Domain: the magic code must be handled with the same "never emitted, logged, or written
      anywhere but the 0600 session file" discipline `auth.py`'s own docstring already establishes for the
      refresh token).
