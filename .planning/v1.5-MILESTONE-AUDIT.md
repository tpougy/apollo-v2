## Tech Debt (non-blocking, all documented)

Four deferred items across phases, all independently confirmed via `git diff` scope
to be **pre-existing and unrelated** to this milestone's own changes — an unscoped
assertion class (heatmap density bands, `--limit 50` list ordering, account-wide

assertion to its own test's created/seeded rows (rather than the whole account) would
retire this recurring class of test fragility in one sweep, rather than continuing to
document each new symptom as it surfaces.
