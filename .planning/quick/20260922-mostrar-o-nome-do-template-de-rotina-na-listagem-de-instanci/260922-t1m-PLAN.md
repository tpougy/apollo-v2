<objective>
Show the source routine template's name on the `instanciasRotina` listing, in both the CLI (`apollo rotina instancia listar`) and the web SPA's instanciasRotina screen, by resolving it through the `instanciasRotina.template` link that already exists in the schema. Read/display only — no schema change, no new editable field, and the existing "never let a user reassign an instance's template" invariant (documented in both `cli/apollo_cli/entities/rotina.py`'s module docstring and `web/src/lib/entities/defs/instanciasRotina.ts`'s prior comment) must remain intact.

Purpose: today an operator looking at the instance list (CLI JSON or the web table) sees `competencia`/`dataPrevista`/`status`/`tipoPrazo` but has no way to tell which recurring routine produced a given row without a separate lookup — a real friction point once an account has many templates (84+ in the production RBR account).
Output: `listar_instancia` emits each row with its `template` sub-record (including `nome`) inline; the web instanciasRotina table renders a `template` column with that name; the web edit form is unchanged (status-only).
</objective>
